# AGENTS.md

Instructions for an AI agent setting this app up for a user, including turning their payslip PDFs into the CSV it reads.

## Install and run

1. Check Node.js 20+ is installed: `node --version`.
2. Clone and install:
   ```sh
   git clone https://github.com/bhaumikkaji/payslip-explorer.git
   cd payslip-explorer
   npm install
   ```
3. Start it with `npm run dev` and give the user the local URL Vite prints. With no data of their own it shows a sample, which proves the install works.

## Build the user's CSV from payslip PDFs

Only do this with the user's own files, on their machine. Never upload payslips or their contents to any web service, and never commit them.

1. Ask the user where their payslip PDFs are.
2. Read each PDF and pull out one row per payslip, using the columns in the README's "CSV format" table. The column names must match exactly. Dates go in as `YYYY-MM-DD`.
3. Map the payslip's line items onto those columns. Payroll systems name things differently, so map by meaning (e.g. "Regular Pay" or "Salary" → `salary`, "Federal/Provincial Tax" totals → `income_tax`, "RSU" or "Stock Award" → `stock_award`). If a payslip has a line item that fits no column, include it in `total_deductions` (if it's a deduction) and tell the user what you did.
4. Leave a cell empty when the payslip doesn't have that item. Don't guess numbers.
5. Write the file to `public/payslips.csv` (gitignored). Check it: every row has a `pay_date`, and for a few rows `gross_pay - income_tax - total_deductions` is close to `net_pay`. Tell the user about any row that doesn't add up.
6. Ask the user to refresh the app.

## Project map

- `src/App.jsx`: the whole app. `COLUMNS` maps CSV column names (and older aliases) to fields; `toRows` parses rows; views are switched by `view`.
- `public/sample-payslips.csv`: made-up data, generated by `scripts/make-sample.py`.
- Run `npm run lint` and `npm run build` before proposing changes.
